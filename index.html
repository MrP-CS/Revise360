What makes it different

🧭

Six stations, one room

No slides to scroll. Students turn to face each station, read the wall, write on the worksheet, then answer.

🛠️

Things you do, not read

Wire logic gates, add binary numbers, paint pixels to see file size, sample a sound wave, set file permissions, defragment a disk.

🥽

VR without the faff

Any headset with a modern browser can enter VR. Nothing to install, and everything works without a headset too.

📄

Paper where it matters

Every experience has a four-page worksheet, so the thinking happens in writing and the headset isn't the whole lesson.

📊

Feedback that names the gap

Scores break down station by station and flag Secure, Revise or Focus here, so revision has a target.

🎮

Challenges they replay

Timed conversion and logic sprints, and a cyber defence game with a budget and consequences. Personal bests, no leaderboards.

How a lesson runs

  1. Starter on paper. Five minutes, no devices, from the worksheet.
  2. Into the room. Six stations: read the wall, write the key fact and the challenge answer, then answer the questions.
  3. Final challenge. Predict on paper first, then test it in the experience.
  4. Score screen. A breakdown by station: secure, needs revising, needs reteaching.
  5. Exam practice. Device away, questions answered from memory.
