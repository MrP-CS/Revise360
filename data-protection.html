Data protection information for schools

The current public site is a local demonstration. It is not yet a hosted school account service. This page distinguishes today's trial from the planned service.

Updated 25 September 2026.

What the trial stores

Demo usernames, PINs, class lists and learning progress are stored in the browser used to create them. They are not shared between school devices. Use fictional student and colleague details when testing the dashboard.

Signing out does not delete the entire local dataset. Clear the site's browser data to remove it from that browser profile. Browser storage is not a school data backup or a secure shared account system.

Resources and web requests

Teachers and students can download available lesson PowerPoints and worksheets. Completed or edited documents are not uploaded by this site. The website, font and library providers still receive ordinary web requests; see the privacy page.

Before a hosted school trial

Hosted progress tracking and teacher Microsoft sign-in are not enabled. Before introducing them, the service's data flows, account permissions, security, retention and hosting arrangements need to be confirmed and documented for participating schools.

  • Define exactly which teacher and pupil information is processed and why.
  • Confirm the providers, processing locations and applicable transfer arrangements.
  • Verify school separation, account revocation, deletion and export.
  • Complete the organisation details and review the school processing agreement.

The draft processing agreement is for review, not evidence that these controls are already deployed. Earlier descriptions of UK/EU-only hosting and PINs never being stored should not be relied on as a description of the current prototype.

Questions and school review

Contact hello@revise360.co.uk with data protection questions or your school's supplier-review requirements. Do not send identifiable pupil data as part of a trial enquiry.
